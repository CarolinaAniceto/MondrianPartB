Descrição decisões tomadas

Guardei a imagem na variável noiseImg, criada com let no início do código para que fosse acessível tanto no setup como no draw. Dentro do setup só lhe atribuo a imagem carregada com await, e é no draw que ela é usada. Criei também a variável amarelo com let depois da noiseImg, para que fosse acessível dentro de ambas as funções.

Para uma das cores poder oscilar, precisei de uma animação, por isso dividi o código em duas funções. O setup é executado apenas uma vez, e o draw é executado continuamente, e redesenha tudo em cada frame. Deixei o background no ínicio do draw para que pudesse limpar o frame anterior, caso contrário, os outros elementos iam-se acumular.

Escolhi o retângulo amarelo para oscilar. Criei a constante osc, que usa sin(frameCount * amarelo) * 12. O frameCount conta os frames, o sin transforma essa contagem num valor que sobe e desce de forma suave, e o 12 define o intervalo da variação, de -12 a +12. Somei osc ao valor verde do amarelo, para o tom mudar ligeiramente. A variável amarelo guarda a velocidade da oscilação e é sorteada com random (0.02, 0.07) dentro do setup, e não no draw, para o valor ser sorteado só uma vez. Assim, a velocidade é diferente cada vez que o sketch é aberto, mas mantém-se constante.
